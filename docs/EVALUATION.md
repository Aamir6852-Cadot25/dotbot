# Evaluation (synthetic simulation)

Generated by `dart run tool/evaluate.dart`. 60 simulated days per student profile, 15-minute ticks from 07:00 to 23:00, identical random seeds for every strategy.

**Assumptions (not a user study):** each day has 3 tasks due 11:00/14:00/17:00; an overdue task is finished alone with a profile-specific chance per tick, higher in the 30 min after a nudge; low-mood episodes last 3h; rituals are written with 80% chance if prompted, 30% otherwise. Every message = 1 LLM call.

| disciplined | Dotbot (policy) | 2.2 | 100% | 76% | 100% | 82% |
| disciplined | Always-nudge bot | 8.2 | 100% | 69% | 100% | 82% |
| disciplined | Fixed reminders | 3.0 | 100% | 63% | 50% | 31% |

## Hint ladder: help fades with mastery

| Mastery | Starts at | Max help | Can reveal full answer? |
|---|---|---|---|
| 0% | hint | answer | yes |
| 20% | question | answer | yes |
| 40% | question | partial | no |
| 60% | question | partial | no |
| 80% | question | hint | no |
| 100% | question | hint | no |

## How to read it
- **Msgs/day** is cost and annoyance: each message spends free-tier quota and attention.
- **Done without a nudge** measures independence: the goal is a user who needs the agent less.
- **Low mood answered ≤1h** checks that silence never costs care.

## Finding that changed the design
The first run showed Dotbot answering **0%** of low-mood moments for the struggling profile: repeated low-quiz nudges spent the daily budget, so it was silent when care mattered most. Fix: low mood now bypasses the budget and the gap, and one-shot nudges (low quiz, broken streak) fire at most once a day. Result: 100% of low-mood moments answered.

## Limitations
- The behaviour model is hand-made; real students differ. A 2-week pilot with classmates is the next step.
- Fixed reminders sometimes score higher on "done without a nudge" simply because they rarely coincide with an overdue task; they miss most low-mood moments and rituals.
